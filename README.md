# Movement LMH v2.5.0

أداة احترافية لموفمنت الدائرة **360°** وتحويل ومضاعفة الأزرار لألعاب الشوتر وفايف ام (**FiveM / GTA V / FPS Games**)، مبنية بمحاكاة عتاد مباشرة (**DirectInput / ScanCode**) وبزمن استجابة **0ms**، من تطوير **أبو فهد (By: Abu Fahad)**.

## المميزات الرئيسية

- **موفمنت الدائرة السلسة (`Circle Strafe WASD 360°`)**:
  - زر تفعيل قابل للتخصيص (افتراضياً `Q` أو `W`) لتدوير الشخصية بحركة دائرية متصلة.
  - اختيار اتجاه الدوران: **مع عقارب الساعة** (`W + D + S + A`) أو **عكس عقارب الساعة** (`W + A + S + D`).
  - تحكم مرن بالسرعة (`30ms` – `120ms`) مع **رادار حي 360°** داخل الواجهة لمتابعة الحركة والزوايا بالوقت الفعلي.
- **تحويل ومضاعفة الأزرار (`Key Remap & Macro`)**:
  - دعم **4 أنماط** للتشغيل: `Dual Press`، `Replace`، `Single Tap`، `Turbo Spam`.
  - إمكانية ربط الأزرار للمراوغة السريعة مثل ربط `W` مع `S` أو `A` مع `D` وإدارتها بسهولة.
- **زر التحكم السريع (`Master Hotkey`)**:
  - زر `F8` افتراضياً (وقابل للتخصيص) للتشغيل والإيقاف الفوري أثناء اللعب بدون الخروج من اللعبة.
- **خيارات إضافية وحفظ تلقائي**:
  - تنبيه صوتي (`Beep`) عند التبديل.
  - إبقاء النافذة بالأعلى (`Always On Top`).
  - التصغير إلى شريط المهام (`Minimize to Tray`).
  - حفظ الإعدادات تلقائياً في ملف `movement_lmh_config.ini`.

## التحميل والتشغيل

1. من صفحة **Releases** في المستودع، حمّل الملف المضغوط `Movement-LMH-v2.5.0.zip` (وفك الضغط عنه) أو حمّل `Movement-LMH.exe` مباشرة.
2. شغّل `Movement LMH.exe` أو ملف `تشغيل_البرنامج.bat` مباشرة على نظام **Windows 10 / 11** (يعمل مباشرة عبر `.NET Framework 4.x` المدمج في ويندوز بدون الحاجة لتثبيت مكاتب إضافية).

## الاختصارات والخطوات السريعة

- **`F8`**: تشغيل أو إيقاف الأداة بالكامل أثناء اللعب (قابل للتغيير من قسم الإعدادات).
- **موفمنت الدائرة 360°**: فعّل الخيار وحدد زر التفعيل واتجاه الدوران والسرعة المناسبة ثم اضغط زر التفعيل داخل اللعبة.
- **تحويل الأزرار**: أضف قاعدة ربط جديدة وحدد زر البداية وزر الهدف ونمط التشغيل المناسب.
